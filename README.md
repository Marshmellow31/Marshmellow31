## Research focus

My current Counter-UAS work explores two defensive, simulation-based tracks:

- **RAC-SRPL:** randomized authenticated anchor audits for detecting formation-preserving GNSS spoofing and bounding absolute swarm displacement.
- **VERGE-CUAS:** uncertainty-aware, collision-conscious clearance of partially responsive drone swarms from protected zones.

The computational package covers reproducible seeded experiments, including a 7,100-trial VERGE-CUAS study. I keep a strict boundary between simulation evidence and real-world deployment claims.
